# JamasADS v3.0-beta.8 — Changelog

**Fecha:** 14 de septiembre de 2026
**versionCode:** 29
**versionName:** 3.0-beta.8

Auditoría del watch: estabilidad de botones, player y chips.

---

## Causas raíz (auditoría con logcat)

1. **Botones que "desaparecían"/parpadeaban**: YouTube re-renderiza la barra de
   acciones y **borra nuestras clases** (`jamas-ab-*`). El layout se quedaba en
   estado parcial (botones sin tarjeta, sparkle visible) hasta el siguiente tick
   del intervalo (1,5 s). Se capturó ese estado con `screencap`.
2. **Video que "no se mantiene arriba"**: el player es `position: fixed`
   (`DIV.player-container.sticky-player`). Lo subíamos a `top:0` por JS cada
   1,5 s; si YouTube re-creaba el masthead, este aparecía un instante y tapaba
   el video (parpadeo/salto).
3. **Chips de relacionados "bugeados"**: los chips de filtro son `sticky` y se
   superponían a las miniaturas al hacer scroll (con el player fijo el offset de
   sticky quedaba mal).
4. **Descripción/título tapados**: el player fijo ocupa la parte superior; al
   bajar, el contenido pasa por debajo. Se agrega más aire arriba del metadata.

## Cambios

- **Observer acotado de la barra** (`observeWatchBar`): `MutationObserver` solo
  sobre la barra (`childList`, sin atributos) con throttle de 120 ms. Re-aplica
  el layout al instante cuando YouTube re-renderiza, sin bucle (no observa
  atributos, así nuestras clases/estilos no lo re-disparan). El intervalo queda
  como respaldo (1 s).
- **Ocultación segura de extras**: solo se ocultan el `<script>` JSON-LD y el
  botón de IA ("Preguntar"). **Nunca** se oculta un elemento con botón que no
  reconozcamos → dislike/compartir ya no desaparecen si aún no tienen
  `aria-label`.
- **Player/masthead por CSS** (estable, sin parpadeo):
  `.player-container { top: 0 !important }` y `ytm-masthead { display: none }`.
- **Metadata con más aire**: `padding: 16px 14px 8px` en la sección de metadatos.
- **Chips de relacionados estáticos** (`position: static`) para que no se
  superpongan a las miniaturas, con estilo pill.
- Se quitaron las reglas CSS que rompían secciones
  (`ytm-item-section-renderer` con `border-radius`/separadores y márgenes del
  carrusel de metadatos).

## Verificación
- A los 9 s el layout es estable y correcto: canal + 2x2 (`19 M` / `519 mil` /
  `Compartir` / `Más`) + comentarios. 0 errores JS.
