# JamasADS v3.0-beta.3 — Changelog

**Fecha:** 14 de septiembre de 2026
**versionCode:** 24
**versionName:** 3.0-beta.3

Rediseño de la UI de la página de video (watch) para que se vea nativa y no
como una página web.

---

## Causa raíz

`enhancements.css` usaba selectores de **YouTube de escritorio** (`ytd-watch-metadata`,
`#title.ytd-watch-metadata`, `#actions.ytd-watch-metadata`, etc.). La app carga
`m.youtube.com`, que usa una maqueta móvil completamente distinta basada en
elementos `ytm-*` y clases `slim-video-*`. Por eso ninguna de esas reglas se
aplicaba y el watch quedaba con el estilo crudo de la web.

Se inspeccionó el DOM real (vía `console.warn` → `onConsoleMessage` → logcat) y
se encontró la estructura móvil:

```
YTM-WATCH
└─ YTM-SLIM-VIDEO-METADATA-SECTION-RENDERER
   ├─ YTM-SLIM-VIDEO-INFORMATION-RENDERER
   │  └─ DIV.slim-video-metadata-header
   │     └─ H2.slim-video-information-title   ← título
   └─ YTM-SLIM-VIDEO-ACTION-BAR-RENDERER
      └─ DIV.slim-video-action-bar-actions     ← avatar + suscribirse + acciones
         ├─ A.slim-video-owner-icon
         ├─ YTM-SUBSCRIBE-BUTTON-RENDERER
         ├─ LIKE-BUTTON-VIEW-MODEL
         ├─ DISLIKE-BUTTON-VIEW-MODEL
         └─ BUTTON-VIEW-MODEL
```

## Cambios

Se añadió una sección nueva al final de `enhancements.css`, **acotada a
`html.jamas-page-watch`** (la clase que pone el watchdog en `<html>`/`<body>`/
`ytm-app`), con los selectores reales de móvil:

- **Título**: máximo 2 líneas (`-webkit-line-clamp: 2`), 17 px, peso 600,
  interlineado 1.34. Antes se cortaba en una sola línea.
- **Cabecera**: separador sutil debajo de la fila de canal/estadísticas.
- **Barra de acciones**: contenedor "pill" glass (fondo translúcido, borde,
  radio 26 px, `backdrop-filter: blur`), con las acciones distribuidas.
- **Botón Suscribirse**: pill roja (#ff0033), texto blanco, radio 20 px.
- **Like / Dislike / Compartir**: botones redondeados con hover.
- **Avatar del canal**: circular.
- **Comentarios**: tarjeta redondeada con borde translúcido.
- **Videos relacionados**: tarjetas y thumbnails con radio 12 px.
- **Separadores** sutiles entre secciones y márgenes del carrusel de metadatos.

Todo está acotado a `html.jamas-page-watch`, por lo que home, search y shorts
no se ven afectados.

## Verificación

- Captura de watch: título en 2 líneas, barra de acciones glass con
  "Suscribirse" rojo, comentarios y relacionados como tarjetas.
