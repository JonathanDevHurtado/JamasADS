# JamasADS v3.0 — Changelog (versión estable)

**Fecha:** 14 de septiembre de 2026
**versionCode:** 32
**versionName:** 3.0

Primera versión estable de la serie 3.x: consolida la UI nativa y los fixes de
la página de vídeo (watch).

---

## Destacado

### UI nativa
- **Bottom nav** de 5 pestañas con iconos Material vectoriales: Inicio, Shorts,
  Buscar, Suscripciones y Biblioteca.
- **Buscador nativo**: la pestaña "Buscar" abre un `AlertDialog` con `EditText`
  y navega a `https://m.youtube.com/results?search_query=<consulta>`.
- **SplashActivity** animado con el logo.
- **Modo inmersivo** permanente.
- **Shorts**: logo oculto y botón nativo "volver a inicio".

### Página de vídeo (watch)
- **Barra de acciones 2×2**: Like / Dislike (fila 1) y Compartir / Más (fila 2),
  con una fila de canal encima (avatar + nombre + suscriptores + Suscribirse).
- **Contador real de dislikes** vía la API pública de Return YouTube Dislike
  (solo se envía el ID del vídeo, una vez por vídeo). El like sale del
  `aria-label`.
- **Comentarios y relacionados** como tarjetas.
- **Audio siempre activo**: `forceAudio()` fuerza `video.muted=false`; se oculta
  el botón `.ytp-unmute`.

### Estabilidad
- **Hueco negro** eliminado: el contenedor del player pasa de `top:48` a `top:0`.
- **Botones que se perdían** en los re-render de YouTube: `MutationObserver`
  acotado (solo `childList`, throttle 120 ms) que re-aplica el layout.
- **Giro del móvil**: al girar a horizontal YouTube elimina Compartir/Dislike del
  DOM y no los repone; al volver a vertical se recarga la página en la misma
  posición del vídeo (`&t=<segundos>`).
- **Reproducción en segundo plano** estable (notificación + `MediaSession`).
